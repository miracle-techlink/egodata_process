# 00 — 课题总览

## 课题名称

- 中文：**基于动态人-物交互建模的行为意图预测研究**
- 英文：**Research on Action Intention Prediction Based on Dynamic Human-Object Interaction Modeling**

## 目标

开发一套面向**人类行为意图提前预测**的视觉感知与交互分析方法：

- **不依赖**对特定场景或特定工具的识别（开放场景、开放物体）
- 通过视觉感知、人体与手部状态估计、目标物体空间运动信息，构建**人—手部—物体**之间的动态交互关系
- 刻画行为发生**之前**交互关系随时间的演化过程
- **预测下一时刻**最可能发生交互的：主体（谁，如左手/右手）、客体（哪个物体）、交互类型（抓握/放置/推拉等）

## 核心技术路线

```
原始长视频
  → ① 视频切分（~20s 片段）
  → ② 手部姿态估计（双手 21 关键点 / 帧）
  → ③ 物体 6D pose 估计（位置 + 旋转 / 帧）
  → ④ 时序样本构建（滑窗）+ 可视化校验
  → ⑤ 动态交互关系编码（人/手/物 → token 序列，含空间关系特征）
  → ⑥ Mamba 时序网络：对连续交互关系进行时序表征与预测
  → ⑦ 集成测试与优化
```

- 时序模型：**Mamba**（状态空间模型，线性复杂度，适合长时序）
- 预测头：下一时刻交互 **主体 / 客体 / 交互类型** 三路输出
- 增强探索：引入**视线（gaze）**等先验信息提升意图预测

## 课题任务书（原始 6 项）

1. 文献综述
2. 视觉目标检测与特征提取算法构建
3. 动态人-物交互关系表示与数据处理
4. 基于公共数据集的时序模型预训练
5. 机电场景下的交互与意图数据集构建
6. 实验验证
