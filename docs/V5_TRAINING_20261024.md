# V5 交互图训练与并行基线（2026-10-24）

## 数据与边界

训练入口使用 `EgoDemoGraphV5Dataset` 的已准入交互子集，不使用 V2 的
`diagnostic=True` 绕过门禁。数据包为 5 段采集、1238 个窗口：

- train/val/test：592/366/280 窗口；
- 训练只覆盖 12 种正例类型，验证/测试另有 9 种训练中没有正例的类型；
- 标签是 assistant silver interaction review，不是完整人工真值；窗口高度重叠；
- `full_annotation_complete` 和 `whole_object_6d_certified` 均为 false。

因此 benchmark 只用于模型结构和训练流程对比，不能作为跨被试泛化、盲测精度或完整数据集结论。

## 模型阵容

三种模型共享完全相同的 V5 输入、`GraphV5Encoder`、`DirectedGraphV5Head`、监督掩码和优化器，只有时间骨干不同：

| 骨干 | 入口参数 | 用途 |
|---|---|---|
| Mamba | `--backbone mamba` | 正式长时序模型，需 CUDA 与 `mamba_ssm` |
| LSTM | `--backbone lstm` | CPU/GPU 循环网络基线 |
| Transformer | `--backbone transformer` | causal `nn.TransformerEncoder` 基础注意力基线 |

Transformer 使用上三角 causal mask 和可学习时间位置编码，未来帧不会影响历史输出；三者输出均为有向实体对上的 66 类多标签 logits。

此外 `eval_v5.py` 报告 all-negative/all-positive 统计参照线，不需要训练。

## 输入/输出

输入来自 V5 loader：`entity_features [B,32,11,120]`、`entity_valid [B,32,11]`、
`entity_kind [B,11]`。模型输出 `graph_logits [B,11,11,66]` 和历史实体预测掩码。
只在 `graph_label_valid` 明确标注的单元上计算 masked BCE；未知单元不是负例。

## 训练命令

本地 CPU 冒烟：

```bash
python3 -m src.mamba.train_v5 --config configs/graph_v5_base.yaml \
  --backbone transformer --device cpu --epochs 1 \
  --run-name cpu_transformer_smoke \
  --data-root runs/egodemo_training_v5_300_20261024
```

服务器正式运行（输出写数据盘新目录，不写冻结数据包）：

```bash
PY=/root/gpufree-data/conda/envs/caron_mamba/bin/python
DATA=/root/gpufree-data/datasets/ego_hoi/egodemo_training_v5_300_20261024
$PY -m src.mamba.train_v5 --config configs/graph_v5_base.yaml \
  --backbone mamba --data-root "$DATA" \
  --runs-root /root/gpufree-data/runs/graph_v5 --run-name mamba_base
$PY -m src.mamba.train_v5 --config configs/graph_v5_base.yaml \
  --backbone lstm --data-root "$DATA" \
  --runs-root /root/gpufree-data/runs/graph_v5 --run-name lstm_base
$PY -m src.mamba.train_v5 --config configs/graph_v5_base.yaml \
  --backbone transformer --data-root "$DATA" \
  --runs-root /root/gpufree-data/runs/graph_v5 --run-name transformer_base
```

三条命令可以在 GPU 显存允许时并行执行；每条 run 独立保存 `best.pt`、`last.pt`、
`manifest.json`、`seen_types.json` 和配置。训练结束后：

```bash
$PY -m src.mamba.eval_v5 \
  --run-dir /root/gpufree-data/runs/graph_v5/mamba_base \
  --checkpoint best.pt --splits val test
```

对 `lstm_base` 和 `transformer_base` 重复执行。test 只在模型完成 val 选择后读取一次。

## Benchmark 指标

报告包括 masked BCE、micro/macro precision/recall/F1、按 operation/relation/transition/cooperation
分层的统计、每类型统计、train-seen/unseen 分组、窗口正例命中率、窗口吞吐和 CUDA 峰值显存，
并同时给出 all-negative/all-positive 参照线。比较时优先看相同 split、相同阈值和相同已知标签掩码下的
micro-F1 与 `macro_f1_seen`，单独查看 unseen 类型，不能将未知单元当作正确负例。
