# 300段自动化复核流水线

入口为 `src/annotation/review_pipeline.py`。它按原300段清单读取实际源文件，自动检查时间轴、手姿态、物体几何/身份、交互标注结构及现有训练子集，生成中文报告和逐区间待处理队列。支持并行、失败重试、断点续跑、按内容变化重检。

## 一条命令运行

在服务器中央仓库执行：

```bash
cd /workspace/egodata_process
/root/gpufree-data/venvs/egodemo_refine_20261023/bin/python -m src.annotation.review_pipeline \
  --config configs/review_pipeline_300.json \
  --output /root/gpufree-data/datasets/ego_hoi/automatic_review_300_20261024 \
  --resume
```

首次执行也可以带 `--resume`。同一输出目录只允许一个进程运行；中断后再次执行上述命令即可。更换数据版本时修改配置中的源目录，建议使用新的输出目录。程序拒绝将运行结果写入任何源数据目录、其父目录或子目录，也拒绝输出目录内预置软链接。

只允许“全部层标注已经完成”时返回成功，可追加 `--require-complete`。这会让仍有未完成标注的运行返回退出码3；不能用普通命令的退出码0推断全标注完成。

## 检查流程

```text
原始选择清单 + V2索引 + 冻结划分/词表
                  ↓
清单一致性、逐段帧数、重复ID、场景/内容泄漏检查
                  ↓
300段并行：源SHA → 原生时轴 → 左右手 → 几何/表面点 → 交互/证据
                  ↓
V5默认Dataset加载 + 所有窗口独立复算（隔离临时目录）
                  ↓
中文报告 + 逐段CSV + 按优先级和原生帧段拆分的复核队列
```

| 层 | 自动核对内容 | 结果解释 |
|---|---|---|
| 来源/划分 | 原始清单SHA、300段集合、逐段帧数、分组、既往暴露、跨划分共享内容 | 不一致报错；缺被试信息时不宣称被试隔离 |
| 时间轴 | 帧索引连续、时间戳有限且严格递增、数组shape | 缺帧、重复、错位报错 |
| 左右手 | 左右顺序、21点mask/NaN、速度、骨长变化 | mask错误报错；速度/骨长异常仅待核；缺测不插值 |
| 物体 | 唯一ID、SE(3)、相机矩阵、材料/位姿范围、已有视觉排除 | 数值错误报错；局部/部件不冒充整物体6D |
| 非刚体 | 表面点CSR、索引界限、点键/归属、同帧重复点 | 非刚体整物体刚体6D不适用，不强补 |
| 交互 | 实体引用、合法范围、已知正负冲突、转换删失、前后证据 | 未知不变成负例，不从事件区间造精确发生帧 |
| 已有视觉审核 | 已保存审核人/来源/范围、manifest及实际审核页SHA | 只核已有记录；生成了图片不等于已经视觉审核 |
| 训练子集 | 固定准入凭据、3个划分默认加载、历史槽位/输入/图mask/未来距离 | 独立重算现有窗口；不启动模型优化 |

手速、骨长变化、物体速度及角速度阈值在配置的 `thresholds` 中明示，只用来定位异常候选。不能把阈值告警当作错误标注的最终判决，尤其是快速真实动作、遮挡和相机运动。

## 输出文件

| 文件 | 内容 |
|---|---|
| `summary.json` | 执行是否完成、自动检查是否通过、全标注是否完成，三个独立状态 |
| `report.html` | 中文结果总览和逐段明细链接 |
| `复核汇总.csv` | 原300段逐项状态、帧数、覆盖及错误/警告/待确认数量 |
| `sequence_reports/<UUID>.json` | 每段每项检查、实际计数及问题原生帧范围 |
| `issues.jsonl` | 所有问题，保留错误、警告与未完成项 |
| `review_queue.jsonl` | 原生半开帧段、实体、原因、下一步操作；合并同类重叠/相邻待办后，每项至多300帧 |
| `training_check/` | 默认Dataset检查与独立重算报告；原V5报告不被覆盖 |
| `jobs.json` | 每项输入内容SHA、代码/配置指纹、尝试次数、产物SHA和缓存命中 |
| `config_resolved.json`、`run_manifest.json` | 实际配置和本次报告/代码校验和 |

可以直接打开 `report.html`；如需浏览器通过HTTP查看，在输出目录运行 `python -m http.server 18792 --bind 127.0.0.1`，再经SSH转发18792端口。流水线本身不启动常驻服务。

队列合并以采集、检查代码、实体、层、严重度及划分相同为前提。`source_issue_lines`指向`issues.jsonl`的一基行号，`messages_zh`与`next_actions_zh`保留当前块的全部原始原因和动作；不同转换事件的原标注和问题记录不合并。复核工作区间重叠时只需查看一次，仍需分别判断每个事件。

## 续跑与失败处理

仅在依赖内容、配置、检查代码及主报告/子产物SHA均一致时复用已完成的成功或待确认结果。manifest引用的证据页是依赖的一部分；单独修改图片也会触发重新检查。缺失文件路径同样进入指纹，补齐后会自动失效重检。失败或中断在 `running` 状态的任务不会被当作成功缓存。

单段错误最多重试 `max_attempts` 次，其他段继续检查。最终报告保留失败段及其原生帧数，不能通过丢弃失败段让统计“通过”。运行过程中输入或检查代码发生变化会报告失败，待版本稳定后续跑。

| 退出码 | 含义 |
|---|---|
| 0 | 自动检查无结构/完整性错误；仍可能有告警或待确认项 |
| 2 | 输入错误、缺少必要数值源、检查失败或运行失败 |
| 3 | 使用 `--require-complete`，自动检查通过但全标注尚未完成 |

## 复核边界

此流水线能自动完成可计算的一致性检查并缩小需要处理的范围。它不会把未查看的视频标为已复核，也不会把可逆矩阵、平滑轨迹、原文动作名称或VLM回答自动认证为真实整物体6D、接触和抓持。缺少可靠观测时仍需补算、纠错或视觉确认。

原始数据、标注、训练准入及冻结包均只读。用户之前确认的V5子集交付验收继续保留，不能用它解除300段的完整标注缺口。自动结果中的 `full_annotation_complete` 与 `automated_checks_passed` 必须分别读取。

## 2026-10-24实际验证

已在原服务器读取300段实际源数组，共868255原生帧；23项清单/来源/划分检查通过。V5以默认正式准入加载全部1238窗口，并独立复算全部1238窗口（train592、val366、test280），未执行优化步骤。

复核发现0项结构性错误、3126条数值告警与8404条待确认问题；同类区间去重后按最多300帧拆为51758条待办。告警是定位候选，不能直接判定标注错误；问题与待办按检查项和实体计数，不能当作不重复帧数。连续语义已复核1995帧、待复核866260帧；340485帧没有可用的场景几何候选，整物体6D及全层标注仍未认证。

`transition_events=52`统计全部已保存转换记录，其中42条为已确认发生的物理转换范围、8条物理删失范围、2条照明信号；不能把52条都叫作已确认物理事件。左右手缺失分别1176和1300帧，可能重叠，不应直接相加为缺手帧总数。

流水线针对性回归80项在本地及服务器全部通过，涵盖并行、失败隔离、内容/代码/证据变更重检、产物篡改失效、输入中途变化、目录保护及重叠待办来源保留。最终全量运行退出0；随后再次核SHA的实际续跑命中全部302个任务，并在`--require-complete`下按预期退出3，保留全标注未完成状态。

运行结果保存在服务器上述`automatic_review_300_20261024/`目录，本地镜像为`runs/automatic_review_300_20261024/`。`full_run_summary.json`保存全量运行结果，当前`summary.json`保存严格门槛下的续跑结果；`run_manifest.json`、`unit_tests.xml`及`independent_acceptance.json`共同保存实际运行证据。独立验收记录绑定的是该次输出SHA，后续运行会产生新状态，不能把旧验收文件当作新运行凭据。
